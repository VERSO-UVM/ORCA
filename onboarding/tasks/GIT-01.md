## Why it matters

ORCA uses Git and GitHub for project management, data storage and code. These are GitHub's own training courses.

You may already know this. Skip any course you can already do.

## Steps

Complete the [First day on GitHub](https://skills.github.com/#first-day-on-github) courses:

- [Introduction to GitHub](https://github.com/skills/introduction-to-github): get started in less than an hour.
- [Communicate using Markdown](https://github.com/skills/communicate-using-markdown): organize ideas and collaborate using Markdown.
- [GitHub Pages](https://github.com/skills/github-pages): create a site from a GitHub repository.
